Manual de Uso — Presupuesto FSE

Qué hace cada herramienta del menú, explicado en palabras sencillas. No necesitas saber de contabilidad para entender cada pantalla.

Idea general: el módulo sigue siempre el mismo camino para cada gasto — primero se aparta la plata (CDP), luego se compromete con un proveedor (RP), después se certifica que ya se recibió el bien o servicio (Obligación) y por último se paga (Orden de Pago). Cada paso no puede pasarse del saldo que le dejó el paso anterior — el sistema lo controla solo.

Principal

Resumen

La pantalla de inicio del módulo. Eliges la vigencia fiscal (el año) arriba y ves, rubro por rubro, cuánto se apropió, cuánto ya está comprometido y cuánto saldo disponible queda — es el "estado de cuenta" del presupuesto en cualquier momento.

Reportes (CHIP/SIA)

Genera el reporte de ejecución presupuestal (ingresos y gastos de la vigencia) en el formato que se usa para rendir cuentas ante el Estado — puedes exportarlo a Excel o a PDF para presentarlo o archivarlo.

Configuración

Vigencias Fiscales

El año presupuestal (ej. 2026). Todo lo demás — rubros, apropiaciones, CDP, RP, etc. — se registra siempre dentro de una vigencia. Se abre una al iniciar el año y se cierra cuando termina; una vez cerrada, ya no se le pueden agregar movimientos nuevos.

Ir
Rubros de Ingreso

El catálogo de "de dónde entra la plata": transferencias del MEN o la Secretaría, recursos propios del colegio, rendimientos financieros, etc. Se crean una vez y luego se usan cada año para presupuestar cuánto se espera recaudar por cada uno.

Ir
Rubros de Gasto

El catálogo de "en qué se puede gastar" — dotación, mantenimiento, servicios públicos, etc. — clasificados como Funcionamiento (gasto de operación normal) o Inversión (mejoras, compras de mayor duración). Cada gasto del ciclo presupuestal debe apuntar a uno de estos rubros.

Ir
Retenciones

Las tarifas de retención que aplican al pagarle a un proveedor: Retención en la Fuente, ReteICA, estampillas territoriales, u otras propias de tu municipio/departamento. Se configuran una sola vez con su porcentaje, y luego se seleccionan al crear una Orden de Pago — el sistema calcula el valor automáticamente.

Ir
Catálogo CGC

El Catálogo General de Cuentas (el "plan de cuentas" contable) que usa el sistema para armar automáticamente el comprobante contable de cada pago. Es de consulta — no necesitas crear ni editar nada aquí para el uso normal del día a día.

Ir

Ciclo Presupuestal

Presupuesto de Ingresos

Cuánto esperas recaudar, por cada Rubro de Ingreso, durante la vigencia (ej. "$5.000.000 en Transferencias del MEN para 2026"). Cuando llega la plata de verdad, se registra el "recaudo" desde el botón correspondiente en cada fila, y el sistema lleva la cuenta de lo presupuestado vs. lo realmente recibido.

Ir
Apropiaciones

Cuánto se autoriza gastar, por cada Rubro de Gasto, durante la vigencia — es el "techo" que no se puede superar. Toda la cadena CDP → RP → Obligación → Orden de Pago se descuenta de aquí, así que esta pantalla es la que muestra el saldo disponible real de cada rubro en todo momento.

Ir
Modificaciones

Cambios a una Apropiación ya aprobada, cuando la plata autorizada no alcanza o sobra: Adición (se le agrega valor), Reducción (se le quita), o Traslado (se mueve valor de un rubro a otro). Toda modificación necesita el soporte de un acto administrativo (ej. una resolución del Consejo Directivo) — el sistema lo pide al crearla.

Ir
CDP — Certificado de Disponibilidad Presupuestal

Paso 1 del ciclo. Antes de comprometerte con un proveedor, "apartas" un monto del saldo disponible de un rubro — es la garantía de que sí hay plata para lo que estás por contratar. Si un CDP ya no se va a usar, se anula para liberar ese saldo de nuevo.

Ir
RP — Registro Presupuestal

Paso 2 del ciclo. Formaliza el compromiso real con un proveedor o contrato específico, a partir de un CDP ya expedido — el valor del RP no puede superar lo que ese CDP apartó. Es la prueba de que "ya se firmó" el compromiso.

Ir
Obligaciones

Paso 3 del ciclo. Se registra cuando el bien o servicio del RP ya se recibió a satisfacción y, por lo tanto, ya se le debe la plata al proveedor. Es el "recibido conforme" que habilita el pago.

Ir
Órdenes de Pago

Paso 4 del ciclo — el pago final. Autoriza el desembolso de una Obligación, aplicando las Retenciones que correspondan. Al crearla, el sistema genera automáticamente el Comprobante Contable y el movimiento de egreso en Tesorería — no hay que registrar nada de eso a mano. Desde cada orden puedes imprimirla o generar su comprobante.

Ir

Contabilidad

Comprobantes

El registro contable de cada pago, generado automáticamente al crear una Orden de Pago. Nace en Borrador para que el contador lo revise; al darle "Contabilizar" queda en firme y ya no se puede editar ni borrar. Si hay un error, nunca se corrige el original — se crea un comprobante nuevo de Reversión que lo anula contablemente.

Ir

Tesorería

Cuentas Bancarias

Las cuentas bancarias del Fondo de Servicios Educativos donde entra y sale la plata. Se registran una vez; luego cada pago y cada recaudo queda asociado a una de ellas.

Ir
Movimientos

El historial de ingresos y egresos de cada cuenta bancaria — se crean solos (un egreso al generar el comprobante de una Orden de Pago, un ingreso al reversarlo), no se registran a mano. Lo único manual aquí es marcar "Conciliar" cada movimiento cuando lo cuadras contra el extracto que envía el banco.

Ir

Almacén

Elementos

El inventario de bienes que administra el FSE: de consumo (se gastan, ej. papelería) o devolutivos (se prestan y se devuelven, ej. equipos). Cada elemento se crea una vez aquí antes de poder registrarle entradas o salidas.

Ir
Movimientos

Entradas (algo que llegó al almacén, normalmente de una compra ya registrada con su RP) y Salidas (algo que se entregó o se consumió) de cada elemento — así el inventario siempre queda al día.
